# Experiment Ledger

No analytical experiment or model run has been conducted. Repository setup and
source-feasibility research are not experiments.

When a meaningful run begins, record a file-based run bundle under
`artifacts/logs/runs/<YYYY-MM-DD__HHMM__tag__gitsha>/` with configuration, seeds
where relevant, source/version references, inputs, outputs, metrics, notes, and
the selection or rejection decision. Add project-local MLflow only if the work
becomes substantive modeling; do not introduce it for deterministic ETL alone.
