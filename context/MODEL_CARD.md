# Model Card — No Project Model Selected

This repository does not currently contain a fitted statistical, machine-learning,
Bayesian, or tsunami-propagation model. An authoritative external travel-time or
arrival product may become an input after feasibility review; it must be labeled
as an external modeled product and documented separately from project-derived
comparisons.

The planned distance-only ring is an explanatory baseline, not a physical
forecast. Its assumptions, metric, propagation speed, and limitations must be
defined before it is implemented. Add a substantive model card only if the
project later owns a model whose outputs are used in the story.
