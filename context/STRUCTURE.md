# Repository Structure

| Path | Owner and rule |
| --- | --- |
| `app/` | Static React/TypeScript story; no secrets or scientific source parsing |
| `pipeline/` | Reusable, typed Python transformations and validation |
| `analysis/story/` | Active tested story-only geometry, diagnostics, plots, and evidence writers |
| `scripts/` | Thin command-line entry points; no unique scientific logic |
| `scripts/story/` | Active thin deterministic story-atlas entry points |
| `notebooks/` | Thin marimo EDA views over reusable pipeline outputs |
| `notebooks/story/` | Active read-only Marimo views of generated story artifacts |
| `config/` | Reviewed, portable source/run configuration without secrets |
| `tests/` | Python behavior, data contracts, and spatial/temporal invariants |
| `tests/story/` | Active story EDA, determinism, seam, runner, and lane-boundary checks |
| `data/raw/` | Ignored source cache; immutable after download |
| `data/interim/` | Ignored checkpoints with accounting and provenance |
| `data/processed/` | Ignored analysis-ready outputs |
| `public/data/` | Ignored generated web assets; never hand-edit |
| `artifacts/provenance/` | Tracked source inventory, contracts, and evidence |
| `artifacts/eda/` | Tracked compact EDA tables/JSON generated by scripts; never hand-edit |
| `artifacts/eda/story/` | Active checksummed preliminary story figures, ledgers, and manifests |
| `artifacts/generated/` | Ignored generated figures/tables until explicitly curated |
| `artifacts/logs/runs/` | Portable run metadata, metrics, notes, and decisions |
| `.mlflow/` | Ignored project-local MLflow tracking state paired to portable run IDs |
| `graphify-out/` | Tracked durable knowledge graph/report; local extraction state ignored |
| `docs/` | Public-facing competition, concept, methodology, and research notes |
| `context/` | Canonical scope, decisions, tasks, validation, handover, and Markdown result reports; retain empty placeholders |
| `context/story/` | Story question, task ledger, EDA decisions, and promoted storyboard state |

Large or awkward scientific formats are transformed into compact static web
assets. Any generated artifact that becomes reportable must be indexed here or
in a later artifact index with its producing command and source-manifest IDs.
The first EDA slice is generated by `scripts/profile_missingness.py`; its thin
reactive view is `notebooks/tohoku_missingness.py`, and
`context/EDA_REPORT.md` is the canonical interpretation.

The visual-story EDA design is
`docs/superpowers/specs/2026-09-14-visual-story-adaptive-eda-design.md`.
Exploratory story artifacts stay outside `app/public/data/`; only a separate
reviewed and checksummed story-export task may promote compact app inputs.
Canonical preliminary atlas evidence is under
`artifacts/eda/story/2026-09-16__0351__story-atlas__6c35d78/`; its portable run
bundle is under the matching `artifacts/logs/runs/` directory. Neither path is
an application export or promoted storyboard primitive.
