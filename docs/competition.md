# PacificVis 2027 Requirements

Verified against the official contest and conference pages on 2026-09-04.

| Item | Current requirement |
| --- | --- |
| Venue | IEEE PacificVis 2027, Busan, South Korea, 19–22 April 2027 |
| Eligibility/topic | Industry or academic individuals/teams; any topic; public data |
| Originality | Original story not previously published; sources and third-party work credited |
| Website form | Runs directly in a browser and guides the reader through a story; a purely analytical/exploratory dashboard is excluded |
| Initial submission | PCS contest track; website/article URL in abstract field, PDF for static work, or MP4 up to 300 MB for video |
| Abstract | 150 words; may cover purpose and analysis/design process; cannot substitute for a self-contained artifact |
| Deadline | 1 February 2027, 23:59 Anywhere on Earth |
| Notification | 15 February 2027 |
| Camera-ready | 1 March 2027 |
| If accepted | 3–6 minute demo video; at least one registration and an in-person presenter according to the currently published pages |
| Judging | Novelty, originality, trustworthy/functioning, engaging/beautiful, informative/enlightening, and requirement compliance |

The conference registration page lists fees but still marks early and author
deadlines as TBA. It says the registering author need not be the contest
presenter. No remote-presentation option, contest-specific PCS deep link, judge
roster, score weights, or detailed accepted-entry video specification is
currently published. Recheck before submission.

Primary sources:

- [PacificVis 2027 Visual Data Storytelling Contest](https://visstory.github.io/2027/)
- [PacificVis 2027 registration](https://pacificvis2027.github.io/registration/)

The React/D3 stack, one-event scope, NOAA preference, Python pipeline,
Pacific-centered projection, and deployment choice are project decisions—not
competition rules.
